# Token icons

- `usdc.svg`: the USDC token logo, unchanged, from Circle's brand kit (circle.com/pressroom, "Download USDC logos").
  USDC and its logo are trademarks of Circle Internet Financial; use them only to refer to USDC, never altered,
  stretched or recoloured, and at least 24 px high (Circle's brand use policy).
- `zusdc.png`: Navora's own icon for zUSDC, the testnet bridge token (not issued by Circle): the original ZP cube,
  pixel for pixel, with a light-blue coin and a dollar sign at its centre (2026-10-16, approved by Alon).
- `zusdc-lockup.png` (white text, dark backgrounds) and `zusdc-lockup-dark.png` (light backgrounds): the icon with a
  "zUSDC" wordmark set in Poppins Medium (SIL Open Font License), tight tracking. Not Circle's wordmark or font.

No testnet address yet?

  1. Open the ZP Wallet and create a new wallet. Use a throwaway recovery phrase, never one you use for real coins.
  2. Make sure the wallet is on the testnet (the "Testnet" tag in its top bar).
  3. Copy the receive address: it starts with tzn1. Mainnet addresses (zen1) are refused.

The coins arrive with the next block, usually within a few minutes. Need more for a larger test? The testnet guide explains how to mine your own.
